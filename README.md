# Python Data Structures and Algorithms

This repository contains study projects and exercises created during Python programming courses.

## Topics Covered

### Object-Oriented Programming (OOP)

* Classes and Objects
* Inheritance
* Polymorphism
* Encapsulation

### Data Structures

* Stack
* Queue
* Dictionary Implementation
* Graphs

### Algorithms

* Depth-First Search (DFS)
* Breadth-First Search (BFS)
* Bracket Validation using Stack
* Reverse Polish Notation (RPN) Calculator

### Sorting Algorithms

* Bubble Sort
* Insertion Sort
* Selection Sort

### Practical Projects

* Library Management System
* Task Queue System
* Custom Dictionary Implementation

## Technologies

* Python 3
* Object-Oriented Programming
* Data Structures
* Algorithms

## Purpose

The goal of this repository is to demonstrate understanding of Python fundamentals, object-oriented programming, data structures, and basic algorithms.
